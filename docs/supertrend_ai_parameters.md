# SuperTrend AI 參數說明與調整指南

SuperTrend AI 的特色在於它會在指定的範圍內產生許多不同的 SuperTrend，並即時針對其歷史表現評分、透過 K-Means 自動挑選最適合當下行情的參數。

以下是這些核心參數的意義，以及如何調整、擴充組合來進行最佳化搜尋：

## 1. `lengths` (ATR 週期長度)
- **意義**：計算市場波動率 (ATR) 的回顧天數。
  - **數值小 (如 10)**：對近期波動非常敏感，停損停利點會更快跟隨股價縮放。
  - **數值大 (如 20)**：用比較長期的平均來衡量波動，指標會比較平滑，過濾掉短期雜訊。
- **如何增加組合**：可以加入常見的 `14` 或 `20`，例如：`lengths=[10, 14, 20]`

## 2. `min_mults` / `max_mults` / `steps` (動態乘數範圍)
- **意義**：這三個參數共同決定了 AI 模型每次要測試哪些「乘數 (Factor)」。SuperTrend 的通道寬度是由 `ATR * 乘數` 決定的。
  - `min_mults`: 乘數的**下限**。較小的乘數（例如 `1.0`）代表通道很窄，對趨勢翻轉極度敏感。
  - `max_mults`: 乘數的**上限**。較大的乘數（例如 `5.0`）代表通道很寬，可以承受較大的回檔而不被洗出場。
  - `steps`: 從下限到上限的**間隔**。如果設定為 `0.5`，當下限 1.0、上限 3.0 時，AI 實際會運算 `[1.0, 1.5, 2.0, 2.5, 3.0]` 五組不同的指標來給 K-Means 分群。
- **如何增加組合**：可以針對下限與上限進行擴充，讓系統比較不同的搜索空間。例如：
  - `min_mults=[1.0, 1.5]` (測試從 1.0 起跳好，還是 1.5 起跳好)
  - `max_mults=[3.0, 4.0, 5.0]` (測試通道最寬要容許到多少)
  - `steps=[0.5]` (建議維持 0.5，設太小例如 0.1 會讓計算量暴增)

## 3. `perf_alphas` (績效記憶 / EMA 衰減權重)
- **意義**：AI 每根 K 線都會評估各個乘數的歷史績效，這個參數控制的是**「歷史記憶的長短」**。
  - 它在底層等同於 EMA (指數移動平均) 的天數參數。
  - **數值小 (如 5.0)**：模型只看重「最近 5 天」的績效，反應極快，只要某個參數這幾天表現好，模型就會立刻切換過去（但也可能容易來回震盪）。
  - **數值大 (如 20.0)**：模型會參考「過去 20 天」的績效表現，切換參數時會比較穩定、沉得住氣。
- **如何增加組合**：可以加入短、中、長的記憶期來讓優化器幫您找最佳節奏。例如：`perf_alphas=[5.0, 10.0, 20.0]`

## 4. `clusters` (分群策略選擇)
- **意義**：在每一根 K 線，AI 會將所有乘數組合的「近期績效」交給 K-Means 演算法分成 3 群（高績效、中等績效、低績效）。這個參數決定我們要採用哪一群的參數作為下一根 K 線的基準。
  - `Best`: 選擇**「績效最高」**的那一群。聽起來最直觀，但在金融市場中，近期表現極端優秀的參數可能會面臨「均值回歸 (Mean Reversion)」或是「過度擬合 (Overfitting)」，也就是過去幾天表現太完美，接下來反而容易失真。
  - `Average`: 選擇**「績效中等」**的那一群。這是一種防禦型策略，它放棄追求絕對的最高分，改為選擇表現平穩、中規中矩的參數，藉此避開極端值陷阱，有時候能帶來更穩定的長線勝率。
  - `Worst`: 選擇「績效最差」的那一群。（通常用於反向測試，實務上較少做為主要策略）。
- **如何增加組合**：`clusters=['Best', 'Average']` 是標準作法，優化器會幫您比較到底追求極端好，還是追求穩定好。

## 5. `long_onlys` (多空雙向交易)
- **意義**：決定策略是否只做多，還是允許做空。
  - `True`: 只在出現多頭訊號時買進，空頭時持有現金。適合長期向上的 ETF。
  - `False`: 多頭時做多，空頭時反手做空。
- **如何增加組合**：`long_onlys=[True, False]` 讓優化器幫您判斷特定標的加入做空機制是否能提高整體分數。

## 💡 如何實際修改與深度掃描？

您只要在 Notebook (`SuperTrend_AI_Backtester.ipynb`) 或 `run_supertrend_ai.py` 腳本中的串列裡加上數字，優化器就會自動排列組合所有可能性。如果您想要進行一場「深度掃描」，您可以把程式碼改成這樣：

```python
res_df, best_params = optimize_supertrend_ai(
    df=df,
    ticker=ticker,
    start_date=start_date,
    end_date=end_date,
    lengths=[10, 14, 20],                 # 測試 3 種波動率週期
    min_mults=[1.0, 1.5],                 # 測試 2 種起點
    max_mults=[3.0, 4.0, 5.0],            # 測試 3 種終點
    steps=[0.5],                          # 間隔固定
    perf_alphas=[5.0, 10.0, 20.0],        # 測試 3 種記憶長度
    clusters=['Best', 'Average'],         # 測試 2 種分群策略
    update_freqs=[1, 5],                  # 測試 2 種運算頻率
    long_onlys=[True, False]              # 測試 單向/雙向
)
```

*(提醒：參數組合的總數是用乘法疊加的。上述參數共有 3 * 2 * 3 * 1 * 3 * 2 * 2 * 2 = 432 組，執行時間會變長。建議您剛開始可以先挑您最想觀察的少數幾個參數去擴充，等確定方向後，再放著讓系統跑完整掃描。)*
