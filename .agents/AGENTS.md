# Workspace Agent Rules

## 語言與溝通規範 (Language & Communication Rules)
- **正體中文強制規範**：所有檔案（包含但不限於 `*_zh.*`、`README.md`、`TechStack.html` 等中文文檔）以及與使用者的所有溝通對話，只要需要使用中文，一律使用**正體中文（繁體中文，Traditional Chinese）**撰寫，絕不得使用簡體中文。
- README.md 與 TechStack.html 使用正體中文編寫，不須產生 README_zh.md 與 TechStack_zh.html

## File format
- Windows line ending
- Unicode UTF-8 no-BOM
